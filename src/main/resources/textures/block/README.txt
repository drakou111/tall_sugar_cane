Block textures from Minecraft 1.16.1, (c) Mojang Studios.

Included so the slot machine looks right without needing a Minecraft install on
the machine running it. They are Mojang's artwork, not this project's, and are
used here only to draw six 16x16 blocks in a toy. If Mojang would rather they
were not redistributed, delete this directory: the code falls back to a local
Minecraft install and then to drawn approximations, so nothing breaks.
